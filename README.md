## Selected engineering work

### [Sentinel AI Platform](https://github.com/orzujon/sentinel-ai-platform) — AI operations + infrastructure automation
A local, GPU-backed incident investigation lab using **FastAPI, Ollama and curated operational runbooks**. The application exposes health/readiness endpoints, structured investigation results, source metadata, mechanical response checks and synthetic evaluation cases. Its infrastructure track explores **guarded Hyper-V VM provisioning, Ubuntu, Ansible and Kubernetes**, with read-only plans, approval gates and audit evidence.

**Status:** Active lab project. AI diagnoses require human review; the inference API is not public-internet ready. One-command clean-room Kubernetes provisioning remains a work in progress.

### [OpsField — Platform Troubleshooting Workbench](https://github.com/orzujon/platform-troubleshooting-hub)
An [interactive, publicly accessible troubleshooting reference](https://orzujon.github.io/platform-troubleshooting-hub/) covering Linux, networking, systemd, Kubernetes, incident decision trees, runbooks and practical scenarios. Static and evidence-first; it does not inspect live environments.

### [KubeMedic](https://github.com/orzujon/kubemedic)
A **read-only Python CLI** for namespace-level Kubernetes pod diagnostics. It inspects pod/container status and produces deterministic findings for CrashLoopBackOff, image pull failures and excessive restarts, with evidence and suggested investigative commands.

### [Branch Protection Checker](https://github.com/orzujon/repository-audit)
A GitHub governance automation proof of concept that audits default-branch review requirements, reports PASS/FAIL/SKIPPED/ERROR and includes explicit fix and reset modes. Mutating modes have important limitations documented in the repository.

### [GKE / Terraform Infrastructure Labs](https://github.com/orzujon/DevOps-GKE)
Hands-on exercises covering **GKE, Terraform, Helm, Workload Identity, GitHub Actions OIDC and environment-scoped infrastructure delivery**. Each level records steps, validation and lessons learned.
